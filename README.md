# FileLib · 本地海量文件资料库

> 面向**十万级本地文件**的视频 / 电子书 / 图片 / 文档资料库管理系统。
> Python 标准库实现，**零第三方依赖**（可选增强：PDF 渲染与封面截图），开箱即用。

---

## 一分钟上手

1. 双击 **`start.bat`**（找不到 Python 会提示安装 3.10+，或把便携 Python 放进 `runtime\python\`）
2. 浏览器自动打开 `http://127.0.0.1:8321/`
3. 首次启动创建管理员账号 → 添加一个资料库（指向你的文件夹）→ 等扫描完成，开始使用

手机 / 平板访问：运行 **`start-lan.bat`**，用同一 Wi-Fi 下的设备打开提示的局域网地址。

|------|------|
| 浏览 | 总览统计、目录树、按类型 / 主题 / 系列 / 作者 / 出版社、随机看一批 |
| **空间分析** | 目录体积 Top12 条形图、顶层目录 treemap 色块图、最大文件 Top15，点击即跳转浏览 |
| 搜索 | 文件名即时搜索 + 语法筛选（`ext:mp4` `tag:xx` `author:xx` `size:>100m`）+ 电子书全文检索（FTS5） |
| 预览 | 视频在线播放（倍速 / 画中画 / 记忆进度）、图片大图（缩放平移）、TXT / EPUB / PDF 阅读器（章节目录 / 字号 / 进度记忆） |
| **继续看 / 随机看** | 看了一半的集中续播（记录可批量删除 / 一键清空）；随机挑一批文件出来逛 |
| **打包下载** | 一键把当前列表打包成 zip 流式下载（≤200 个 / 2GB，不占临时磁盘） |
| **文件管理** | 在当前目录一键新建文件夹（Windows 保留名 / 非法字符 / 路径穿越全拦截） |
| 整理 | 一键整理流水线、重复文件检测（含跨库对比）、清理建议、备份索引 |
| 标记 | ⭐ 收藏 / ✅ 已读 / 🕐 待读 + 自定义标签 + 播放/阅读进度记忆 |
| **趣味（v1.0.4）** | 今日推荐（每日一本+摘录，同日稳定）、阅读统计打卡热力图（连续天数 / 累计时长）、拟物书架（收藏 / 待读书脊视图）、TTS 听书（浏览器朗读 / 语速 / 自动续读）、老板键（按 `` ` `` 一键伪装成代码编辑器） |
| **封面 / 缩略图（v1.0.5）** | 缺图**按需现场生成**（限 3 并发，不再整库苦等）、生成提速（JPEG 草稿采样 3~5 倍）、存量重压缩省约 40% 空间（🗜 工具）、无图书脊占位美化、Calibre 兜底改为默认关（后台开关） |
| **管理（v1.0.5）** | 后台用户列表 🔑 一键重设密码；改他人密码后该账号全部旧会话立即失效（本人除外） |

| **自动标签（v1.0.7）** | 🧰 一键按文件名 / 目录规则 + 内嵌元数据（音频 ID3、EPUB、照片 EXIF）+ 正文关键词自动打标：带「自动」角标与人工标签区分，人工永远优先；侧栏按 全部 / 人工 / 自动 筛选，可一键清空重来 |
| **体验增强（v1.0.7）** | 手机 / 平板「添加到主屏幕」PWA 离线外壳（秒开）、登录页记住用户名 + 锁定倒计时提示、图片幻灯片轮播、视频关闭收纳为迷你播放条（可暂停 / 展开）、文档卡片正文摘要、备份瘦身（按保留份数清理）、TLS 证书启动参数、初始化命令一键复制 |

| 安全 | 会话 + CSRF 三重防护 + 越权拦截 + 限流 + 路径穿越防护，详见《安全说明》 |

## 性能（实测）

| 场景 | 结果 |
|------|------|
| 10 万文件翻页（深页码） | 661ms → **85ms**（热缓存） |
| 2000 文件库深翻页 / 全文搜索 | **22–39ms / 28–36ms** |
| 8 并发混合请求 | **113 req/s** |

技术：SQLite WAL + FTS5(trigram) + 虚拟滚动 + 热缓存 + 流式响应。

## 目录结构

```
filelib/
├─ server.py            # 唯一入口：HTTP 服务 + 全部 API 路由
├─ start.bat            # Windows 一键启动（本机访问）
├─ start-lan.bat        # 局域网访问（手机 / 平板）
├─ filelib/
│  ├─ core/             # 扫描器 / 存储 / 数据库 / 分类 / 搜索
│  └─ ui/               # 单页面前端（app.js + app.css + index.html）
├─ tools/               # 重置密码、生成图标、性能基准等工具脚本
└─ tests/               # 零依赖自动化测试（python tests/test_all.py）
```

## 数据在哪

- 索引、封面缓存、会话数据都在**本机**，不联网、不上传
- 默认位置：`%LOCALAPPDATA%\FileLib\`；与程序同目录存在 `data\` 时用便携模式
- **原文件只读不写**（扫描/预览除外），所有整理建议先预览后执行

详细说明见《部署文档》第三节。
